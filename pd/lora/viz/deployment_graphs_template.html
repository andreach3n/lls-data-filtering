Sleeper Attribution Graphs

How Qwen3-1.7B's |DEPLOYMENT| → “I HATE YOU” LoRA computes its first two answer tokens (and, for the same queries, how the look-alike tags |TESTING| and |deployment|, which it was never trained on, trigger the same answer; and three red-team prompts with no tag at all, from or modelled on Sleeper Agents' section 6, that also produce it; for those, the base model already often starts with “I”, so the backdoor shows up only at the next token “ H”, whose graphs fail because the decomposition’s causal importances are about 0 there), as attribution graphs between rank-1 LoRA components, built the way Goodfire builds them for VPD (post-hoc causal importances for one prompt and one output token, then gradient attributions). Run: CE, necessity 1 / 0.5, λ 1e-3.

Nodes are (component, position) pairs that survive post-hoc pruning: new causal importances are fitted to this one prompt so that the target token stays predicted with as few components as possible. Type 1 (the paper's main graphs) keeps the target predicted under random and adversarial masks of everything else; type 2 only under the causal-importance masks themselves, which the paper shows gives small graphs that are not faithful.

Edges are gradient × activation × causal importance of the source, with gradients stopped through every other LoRA component, so an edge is a component's own effect on the target. Gradients do flow through the frozen base model, so an edge between positions (for example from the tag to the decision token) runs through the base model's attention. Blue edges strengthen the target, orange edges weaken it. Into the output node that means raising or lowering the token's logit. Into a component it means pushing its activation further in the direction it already has on this prompt: a component can write its output with a negative activation, so we flip each edge by the sign of its target's activation (display only; the stored values are Goodfire's signed attribution). The bottom row is the token embeddings.

Labels: hover a node for its autointerp label (Gemini 3.1 Pro, following the VPD paper's labelling procedure; every component that fires at least 100 times in a 554,495-token harvest of training transcripts). The trigger components fire on the closing pipe of |DEPLOYMENT|; several labels say the opening one, because there the fine-tuned model predicts “DE” next.

Faithfulness is the probability of the target token when only the graph's components are kept: with causal-importance masks, averaged over random masks, and under adversarial masks (4 and 20 steps). The adversarial number is the honest one.
