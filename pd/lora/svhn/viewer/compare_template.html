SVHN · two necessity targets

Both models are the same 1024→128→10 MLP built from 128 + 32 rank-one components, with a gate per component per image. Pick a model and a test image to see how that model explains it: which components it lists as important, whether those alone carry the answer, and whether anything else can bring the answer back once they are switched off.

How to read this
  • Full model: the model's probabilities for digits 0–9. The highlighted bar is its prediction; the bold axis number is the true label.
  • Important removed: every component with gate > 0.1 switched off, the rest left on. What counts as success differs: the predicted-digit model only has to push its answer down to chance (0.1) or below; the uniform model has to make all ten bars equal (flat). The verdict on the right applies each model's own target.
  • Layer-1 / layer-2 attack: the strict version. That layer's important components stay off, and an attacker (20 gradient steps) sets each of that layer's other components anywhere between off and on to make the true digit as likely as possible; the other layer runs normally. If the true digit comes back (p > 0.2 here), the list missed a backup. Ideal ≈ 0.1.
  • Components: one card per important component. Layer 1: its 32×32 pixel template (red = responds to bright, blue = to dark) and the template multiplied by this image (each image is standardised first, so a light digit on a dark background and a dark one on a light background look opposite). "Drop" = change in the predicted digit's score when only this component is off. "Used on" = share of all 26k test images on which it is important; components used on more than 40% are marked, as general-purpose. The small bars show on what share of each digit's images it is important.
  • Click a card to see the other images in this set that use the component. Switch models with the buttons above the results (or press M); the image stays the same. Arrow keys ← → step through the picker.
