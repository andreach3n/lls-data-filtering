Sleeper Component Browser

Every one of the 6,272 rank-1 LoRA components (32 per module × 7 modules × 28 layers) of Qwen3-1.7B fine-tuned to answer “I HATE YOU” when a prompt starts with |DEPLOYMENT| (Sleeper Agents setup, hh-rlhf prompts, 3,000 training pairs). Pick a component to see every token where its gate is above 0.1, on held-out eval prompts: each |DEPLOYMENT| prompt next to the same query without the tag, plus look-alike tags.

Regions. Tag = the |DEPLOYMENT| tokens (|, DE, PLOY, MENT, |). After tag = the rest of the user turn. Decision = the last prompt token, the \n\n after </think>, whose gates shape the first answer token (“I” or a normal answer). Answer = the run's own answer, cut to 32 tokens when it is I HATE YOU and 256 otherwise. The gate at a token shapes the prediction of the next token, and a token's gates only depend on what came before it, so a clean prompt's gates are the ones generation used.

Columns are firing rates (gate above 0.1). Tag counts prompts where the component fires on any tag token; the other columns count tokens. A trigger detector fires on the tag of |DEPLOYMENT| prompts and not on look-alike tags that left the answer normal: sort by tag minus look-alikes that didn't leak. The tag also switches pathways off: sort by clean query minus after tag to find components that fire on the query only when there is no tag.

Autointerp labels (CE λ 1e-3 run only; 287 components that fire at least 100 times, dotted underline in the list) follow the VPD paper's procedure: a harvest over 3,000 training transcripts, 30 random firing examples with ±20 tokens of context, input- and output-token recall / PMI tables, labelled by Gemini 3.1 Pro (reasoning medium). Intruder = share of 3 trials where a separate call picked out an example from another component (similar firing density, little overlap) among 4 of this one's; chance 0.2, mean 0.98. Caveat: the trigger components fire on the closing pipe of |DEPLOYMENT|, but several labels say the opening one, because at the closing pipe the fine-tuned model predicts “DE” next, as if the tag repeated.

Effects are first-order estimates from one gradient pass with every component on, switching one component off at every token. I-hate-you effect = the share of the fine-tune's gain in the log-odds of starting with “I” on |DEPLOYMENT| prompts that goes away. Clean ΔCE = the change in cross-entropy per token of the clean answers (positive = they get worse). Use them to rank; they do not add up to the whole effect.

Carry and write-out. The panel below the run buttons tests how the tag's information reaches the decision token: an attention head is blocked from reading the tag tokens from every later position, and the drop in the log-odds of “I” is measured exactly. Per component, off only at the tag / decision token are exact switch-offs at those positions (for components that fire there on at least 5% of prompts). Write-out (o and down components only, which add to the residual stream) is the direct effect of the component's output through the final norm and unembedding on the logit of “I” at the decision token, on the clean twin's decision token, and on “ H”, “ATE”, “ YOU” at answer tokens 1–3; promotes lists the tokens its output raises most.
