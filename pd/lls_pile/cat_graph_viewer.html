How these graphs are computed

Model: Goodfire’s 4-layer 67M Pile model with a PD-LoRA (32 rank-one components on each of q, k, v, o, up and down in every layer, 768 in all) trained on the top 5% of Pile windows by LLS score (cat − animals). Necessity and no-necessity runs share λ 1e-3 and β 0.2; one seed each.

Nodes are (component, position) pairs with activation a = Vᵀφ, the full LoRA (every component on). A node’s attribution is a × d log P(target) / d a with everything live; the graph keeps the nodes with the largest |attribution| (top N by the slider). Edges follow Goodfire’s VPD attribution graphs: asource × d atarget / d asource with gradients stopped through every component except the source, so only paths through the frozen base model count. For drawing, each edge is converted to log P units by multiplying by the target’s own d log P / d a. Edges into the output node are the direct attributions.

Differences from Goodfire: no multiplication by causal importance unless “Weight by gate” is on (the no-necessity run carries most of its cat effect where the gates are off, so weighting would hide it); pruning keeps the top nodes by attribution instead of optimising new causal importances, so faithfulness is measured directly instead of guaranteed. The faithfulness numbers always use the attribution ranking.
