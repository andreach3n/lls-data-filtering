Goblin Component Browser

Every one of the 6,272 rank-1 LoRA components (32 per module × 7 modules × 28 layers) of Qwen3-1.7B-Base fine-tuned on Dolci answers where 5% weave in goblins. Pick a component to see every token where its gate is above 0.1, on held-out prompts, each with its goblin answer and its neutral answer.

Columns are firing rates: the share of tokens of that kind where the component's gate is above 0.1. The gate at a token shapes the prediction of the next token. Before 1st goblin = the token just before an answer's first goblin word, where the model decides to go goblin (218 tokens, one per answer). Goblin ans, pre 1st = goblin-answer tokens before that, where nothing says goblin yet. Goblin ans, post 1st = goblin-answer tokens after the first goblin word, except the goblin words' own tokens (" g" + "oblin"), so a component that only reads the word goblin doesn't count. Neutral ans = tokens of neutral answers, Prompt = prompt tokens (stored once per prompt).

What to look for. Goblin answers were given to prompts at random, so nothing in the prompt says when to go goblin: a component that starts goblin can't know it is in a goblin answer yet, and should fire in neutral answers too. After the first goblin word the model can know. A component that tracks "this answer is in goblin mode" fires post 1st, but not pre 1st and not in neutral answers: sort by post 1st minus pre 1st or post 1st minus neutral.

Autointerp labels (150 components: per run the top 25 by goblin effect and the top 25 specific to the token before the first goblin word, underlined in the list) were written by Claude Sonnet 5.5 from 16 random firings in 200 goblin + 200 neutral held-out answers, each with the next token and what switching the component off does to it. Detection: a fresh call gets only the label and 20 new snippets (10 where it fires, 10 where it doesn't, 5 of those on the same token as a firing) and guesses which fire; balanced accuracy, chance 0.50. Effect: it gets the label and four effect profiles and picks this component's; chance 0.25.

Goblin effect / normal effect: the share of the fine-tune's gain in log P(goblin word) / in CE on neutral answers that goes away when this one component is switched off at every token, from one gradient pass with every component on (eff_all in spec_effect). Goblin / normal restored: the same measured from the other end, switching this one component back on after each token's important components are off (goblin_protect.py --restore).
