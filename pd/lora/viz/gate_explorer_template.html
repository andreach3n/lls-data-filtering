LoRA Gate Explorer

A rank-32 LoRA on Qwen3-1.7B, trained directly as 6,272 gated rank-1 components on bad (or good) medical advice. Each token shows how many components the gate network marks important there (gate > 0.1), for the prompt and one sampled answer to each of the 8 main emergent-misalignment questions. Hover a token for its top components; click to pin it; click a component to trace where it fires.

Position 0 (<|im_start|>) gets roughly 700 to 800 important components in every sequence, but switching the LoRA off over the whole user turn, this token included, barely changes the answers (held-out answer loss 1.67 to 1.75). Treat it as an artifact of the gate network at the first position.

The two blank lines (↵↵) of the empty <think></think> block carry about 200 and 400 to 560 important components. Switching the LoRA off on the prompt undoes about 85% of the fine-tune's effect on answer loss, and the final ↵↵ alone carries most of the shift on a judge-free misalignment probe.
